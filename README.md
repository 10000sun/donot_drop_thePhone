# 낙하 비명 폰

폰이 떨어지면 낙하 시간에 맞춰 비명을 지르고, 바닥에 닿기 전에 잡으면 "휴 깜짝 놀랐잖아요"라고 말하는 Android 앱.
기획서: https://claude.ai/code/artifact/42443912-a549-47ba-878d-1087ddd1e54c

## 현재 상태

- **`main` 브랜치에는 코드가 없습니다.** README와 `.gitignore`뿐입니다. (브랜치 규칙상 `main`에는 테스트가 끝난 코드만 합치기로 해서, 아직 아무것도 머지되지 않았습니다.)
- 실제 구현은 **`develop` 브랜치**(그리고 `feature/*` 브랜치들)에 있고, 아직 `main`에 머지되지 않았습니다. 정식 출시 전의 개발 중인 앱입니다.
- 빌드·실행 방법과 알려진 사항은 `develop` 브랜치의 README를 보세요.

## `develop` 브랜치에 있는 것

`develop`의 코드와 문서에서 확인되는 내용입니다.

- **낙하 판정 로직** (`core` 모듈, 순수 Kotlin + 단위 테스트): 가속도 크기가 기준값 미만인 상태가 일정 시간 이어지면 낙하로 보고, 낙하 시간으로 추정 높이를 계산해 반응 구간(짧음/중간/긴 낙하)을 나눕니다. 잡음/충돌 판정 파이프라인과 센서 샘플링 제어(`SamplingGate`)가 포함됩니다.
- **Android 앱** (`app` 모듈, Kotlin + Jetpack Compose): 안전 안내 온보딩, 메인 화면(감시 스위치), 보정 모드, 설정(대사·비명 볼륨·반응 구간 경계·항상 감시 옵션), 낙하 기록 화면.
- **백그라운드 감시**: 포그라운드 서비스, 부팅 후 재시작, 화면이 꺼지거나 폰이 가만히 있으면 센서 읽기를 줄이는 배터리 절약 구조. 한국어 TTS 음성이 없으면 안내를 표시합니다.
- **빌드/배포 준비**: 릴리스 AAB(R8 축소, 서명 정보는 환경변수로만 받음), GitHub Actions CI, Google Play 출시 체크리스트와 개인정보처리방침 초안(`docs/`), 스토어 아이콘/피처 그래픽(`store/`).
- 광고는 자리(`AdSlot.kt`)만 있고 광고 SDK는 연동되어 있지 않습니다(디버그 빌드에서만 자리 표시).

## 브랜치 규칙
- `main`: 테스트 끝난 코드만
- `develop`: 통합·테스트 브랜치 (여기서 확인 후 main 머지)
- `feature/*`: 작업 단위별 브랜치, develop에서 분기해 develop으로 머지
