## 직접 해야 하는 것
1. **applicationId 확정**: 지금 `com.donotdrop.phone`. 업로드 후에는 변경 불가.
2. **업로드 키 생성**(분실 방지, 저장소 커밋 금지):
   `keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000`
   빌드 시 환경변수 `UPLOAD_KEYSTORE_PATH`, `UPLOAD_KEYSTORE_PASSWORD`, `UPLOAD_KEY_ALIAS`, `UPLOAD_KEY_PASSWORD` 지정. Play 앱 서명 사용.
3. **개인정보처리방침 URL**: `docs/privacy-policy.md`를 웹에 게시(예: GitHub Pages)하고 문의 이메일 기재.
4. **스크린샷**: 폰 화면 2장 이상(메인, 보정). 실기기에서 캡처.
5. **versionName**을 출시 버전(1.0.0)으로.
6. 개인 개발자 계정이면 비공개 테스트 요건 확인(Play Console 안내).

## Play Console 양식 답안 초안
**포그라운드 서비스 (specialUse)**
- 설명: 사용자가 켠 동안 가속도 센서를 계속 읽어 폰이 떨어지는 순간을 감지하고 즉시 소리로 반응하는 앱의 핵심 기능. 앱이 화면에 없을 때도 감지해야 하므로 포그라운드 서비스가 필요하며, 상태 알림으로 항상 표시됨. 대체 유형(위치, 미디어 재생 등)에 해당하지 않음.
- 영상: 감시 켬 → 알림 표시 확인 → 쿠션 위 낙하 테스트 → 소리 재생을 보여주기.

**데이터 보안**: 수집 없음(센서 값은 기기 내 처리). 광고 연동 시 '기기 또는 기타 ID'(광고 ID) 수집·공유 체크, 광고 목적.
**광고**: '광고 포함' 체크. **대상 연령**: 13세 이상(어린이 대상 아님). **콘텐츠 등급**: 설문에서 폭력·위험 콘텐츠 없음.

## 스토어 문구 주의 (위험 행동 정책)
폰을 던지거나 일부러 떨어뜨리라고 권하는 표현 금지. "실수로 떨어뜨리는 순간 반응하는 재미 앱", "테스트는 침대·쿠션 위에서" 문구를 넣는다. 이후 '던져 올리기 모드'는 정책 위험이 있어 출시 전 재검토.

## 짧은 설명 / 상세 설명 초안
- 짧은 설명(80자): 폰이 떨어지는 순간 비명을 지르고, 바닥에 닿기 전에 잡으면 안도하는 앱
- 상세: 가속도 센서로 폰의 낙하를 감지해 떨어지는 순간 소리로 반응합니다. 바닥에 닿기 전에 잡으면 "휴 깜짝 놀랐잖아요"라고 말합니다. 낙하 시간과 추정 높이를 기록하고, 보정 모드에서 감지 기준을 조정할 수 있습니다. 안전을 위해 폰을 일부러 던지거나 떨어뜨리지 마세요. 테스트는 침대나 쿠션 위에서 하세요.
